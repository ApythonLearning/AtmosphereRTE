# ARTE Atmosphere

面向地气系统建模与大气辐射传输的独立桌面软件。

## 主要能力

- 读取 MOD11 陆地温度、海表温度、MOD08 云和 MCD12 地表类型，生成统一经纬度地球环境网格与 NPZ 缓存。
- 可选读取 MERRA-2 M2T1NXAER 的 AOD550 与 Ångström 指数；未提供时按能见度估算气溶胶光学厚度。
- 35 层 Beer–Lambert、层源函数与 δ-Eddington 型散射传输；包含地表、液态水云、OPAC 气溶胶、瑞利散射和 TSIS-1 太阳参考谱。
- 快速地球盘积分光谱与高分辨率目标单柱光谱；单柱模式支持卫星天顶角/方位角，并按逐层 `tau/cos(卫星天顶角)` 计算斜视路径。
- 从 NUCAPS 廓线调用 HAPI/HITRAN 生成 35 层逐波数总吸收光学厚度；加载结果时自动采用同目录 `atmospheric_profile_35_layers.csv` 的分层温度。
- 从历史 HAPI 结果训练全球大气廓线模式，支持非线性自编码器或 PCA/EOF 降维、K-means 代表状态选择和分层光学厚度快速插值。
- 支持本地导入原始 HITRAN `.par` 文件或 HAPI `.data/.header` 文件对；完整文件对直接原地引用、不重复复制，并随项目保存其外部路径。
- 导入 CSV/TXT/DAT、NPZ、NetCDF、HDF5 卫星光谱，计算 RMSE、NRMSE、MAE、Bias、相关系数和光谱夹角；CrIS 验证采用官方三点 Hamming 权重并支持过采样仿真的 sinc 仪器线型卷积。
- 高分辨率验证以同足迹 NUCAPS 云量为弱先验，仅使用 8.0–9.2 和 10.2–12.5 μm 大气窗口的晴空/全云端元拟合辐射有效云量，避免强气体吸收带误差污染云量。


原软件中的“开发者模式”限制已移除，分层光学厚度和光谱验证可从主导航直接进入。

## 安装与启动

建议使用 Python 3.11 或 3.12：

```powershell
python -m venv .venv
.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
python main.py
```

`pyhdf` 仅用于 HDF4 MODIS 产品；若只读取 HDF5/NetCDF 或已有环境缓存，可不安装它。首次 HAPI 计算可能需要联网下载 HITRAN 谱线，下载结果会保存在工作目录。

## 推荐工作流

1. 在“地球环境与大气辐射”页选择四类环境产品并生成缓存，或直接加载已有缓存。
2. 如需高分辨率计算，在“分层吸收光学厚度”页从 NUCAPS 生成 35 层 CSV，或导入已有 CSV。
3. 设置足迹位置、卫星高度、太阳方向、卫星观测方向和物理选项，执行快速地球盘或高分辨率单柱求解。
4. 在“大气光谱验证”页导入卫星产品进行共同波段匹配与残差分析；若光谱旁存在同名 JSON，软件会自动读取经纬度、卫星高度及太阳/卫星观测角，几何变化后需重新求解。

输出与 HAPI 数据默认保存在界面右上角设置的工作目录。仓库内自带 TSIS-1 HSRS v2 太阳参考谱和 HAPI 程序，但不捆绑大体积 HITRAN 数据库、NUCAPS/MODIS/MERRA-2 或卫星观测样例。

项目保存在工作目录的 `arte_atmosphere_project.json`。点击“保存项目”可立即保存；关闭软件时自动保存。再次启动时会读取 `.arte_atmosphere_recent.json` 指向的上次工作区，并自动恢复可用缓存和最近光谱。“打开项目…”可读取其他工作区中的项目 JSON。

## 大气廓线模式学习

“大气廓线模式学习”工作台可以直接读取下载脚本生成的全球 GFS 合并 `.nc4` 文件、全球 NUCAPS `.nc/.nc4` 产品，也可以扫描所选目录下的35层廓线。GFS 按月份分块读取并在内存中守恒映射到35层，不生成逐廓线缓存。学习阶段只使用温度、气压和气体廓线，不调用 HAPI；训练完成后自动导出少量最终代表模式，随后才由用户将代表模式发送到 HAPI 工作台计算光学厚度。

训练完成后，页面内的“训练结果可视化”工作台会直接显示：模式样本数量与训练收敛曲线、可按月份和模式筛选的全球经纬度分布、温度/H₂O/O₃代表廓线及模式内10%—90%区间，以及二维潜在特征空间。星形点表示最终代表模式。可视化模型只额外保存样本模式编号、经纬度、时间、潜在坐标和模式统计量，不保存原始全球三维场；旧版模型仍可读取，但需要重新训练一次才会具备完整可视化数据。

GFS 模式学习使用其真实提供的温度、气压、H2O 和 O3。为了让最终代表模式能够计算主要气体吸收，导出的35层CSV另补充固定干空气背景 CO2=425 ppm、CH4=1.95 ppm、N2O=338 ppb、CO=100 ppb；这些补充列不参与聚类，不应视为对应气体的全球时空反演结果。

推荐流程：

1. 在模式学习工作台选择 `resources/data/atmospheric_profiles/gfs_global_202508_202607/gfs_global_profiles_202508_202607_1deg.nc4`，或选择 NUCAPS/35层廓线目录。
2. 设置代表模式数量并执行训练。该过程直接学习全球廓线，不计算任何光学厚度；GFS 的统一35层处理仅在内存中进行。
3. 训练结束后，点击“批量计算全部最终模式”，软件会将全部代表廓线装入HAPI工作台。统一设置一次波数范围、精度和输出选项后，点击“开始批量计算全部 N 个代表模式”；任务逐个模式执行，可随时取消，避免多个HAPI任务同时运行造成内存峰值。
4. 全部模式成功后，软件自动校验各结果的35层结构与波数网格，并将光学厚度绑定到当前模式模型，供运行时新廓线快速匹配和插值。个别模式失败时会保留已完成结果并列出失败模式，但不会启用不完整的插值库。
5. 在“训练结果可视化”的“全球模式分布”中按月份检查空间覆盖，在“代表性廓线”中按住 `Ctrl` 叠加多个模式；也可直接点击该页的“在HAPI中打开选中模式”。
6. 如需运行时快速近似，可选地在所有代表模式完成统一光谱网格的精算后使用插值库；这不是模式学习的前置步骤。

模式模型默认保存在工作目录的 `config/atmosphere/profile_patterns/atmospheric_pattern_model.npz`，项目保存时记录并自动恢复模型路径。插值结果保存在其 `predictions` 子目录。

## 全球廓线样本数据

`scripts/download_gfs_profile_snapshots.py` 可从 NOAA GFS 公开历史分析档案按 GRIB2 消息范围提取全球廓线，不下载完整分析文件。默认选取每月15日00 UTC，保留41个压力层的温度、比湿、臭氧质量混合比以及地表气压和地形高度，并将0.25°原始网格按4点抽样为约1°压缩 NetCDF。脚本一次只解码一条 GRIB 消息，不创建持久 GRIB 缓存，并支持从合并文件的 `completed_dates` 属性继续未完成任务。

下载脚本的附加依赖位于 `scripts/requirements-download.txt`。生成的数据目录已由 `.gitignore` 排除，不会上传到 GitHub。
