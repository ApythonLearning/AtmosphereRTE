# NOAA-20 CrIS 光谱验证数据说明

## 1. 数据概览

本目录保存 NOAA-20（JPSS-1）Cross-track Infrared Sounder（CrIS）在
2025-02-03 的全光谱分辨率 Level-1B/SDR 辐亮度数据，以及从原始产品中提取的
两个单视场软件验证文件。

| 项目 | 内容 |
|---|---|
| 产品 | NASA `SNDRJ1CrISL1B` V3；NOAA `CrIS-FS-SDR` |
| 原始文件 | NASA `SNDR.J1.CRIS.20250203T0000...nc`；NOAA `SCRIF...h5` + `GCRSO...h5` |
| 产品覆盖时间 | 2025-02-03 00:00:00–00:06:00、00:40:58.9–00:41:28.7 UTC |
| 软件验证文件 | `cris_noaa20_20250203T0000_validation.npz`、`cris_noaa20_20250203T004059_45S168W_validation.npz` |
| 验证文件变量 | `wavenumber_cm`、`radiance_w_m2_sr_um` |
| 提取程序 | `scripts/extract_cris_validation_spectrum.py`、`scripts/extract_noaa_cris_sdr_spectrum.py` |
| 官方下载地址 | <https://data.gesdisc.earthdata.nasa.gov/data/JPSS1_Sounder_Level1/SNDRJ1CrISL1B.3/2025/034/SNDR.J1.CRIS.20250203T0000.m06.g001.L1B.std.v03_08.G.250203073617.nc> |

## 5. 光谱范围与单位

| 波段 | 波数范围（cm⁻¹） | 波长范围（μm） | 通道数 | 波数间隔（cm⁻¹） |
|---|---:|---:|---:|---:|
| LW | 648.75–1096.25 | 15.4143–9.1220 | 717 | 0.625 |
| MW | 1208.75–1751.25 | 8.2730–5.7102 | 869 | 0.625 |
| SW | 2153.75–2551.25 | 4.6431–3.9196 | 637 | 0.625 |
| 合计 | 648.75–2551.25 | 15.4143–3.9196 | 2223 | 三个独立波段 |

三个波段之间存在仪器未观测的光谱间隙，验证文件没有在间隙中生成或插值数据。

原始 CrIS 辐亮度单位为 `mW/(m²·sr·cm⁻¹)`。为与软件的大气辐亮度波长谱一致，
提取文件将其换算为 `W/(m²·sr·μm)`：

```text
L_lambda = L_wavenumber × wavenumber_cm² / 10⁷
```

## 7. 在软件中使用

1. 打开“大气光谱验证”模块。
2. 在“卫星产品光谱”中选择所需样本；目标位置使用
   `cris_noaa20_20250203T004059_45S168W_validation.npz`。
3. 光谱坐标选择 `wavenumber_cm`，坐标类型选择“波数（cm⁻¹）”或“自动识别”。
4. 光谱值选择 `radiance_w_m2_sr_um`。
5. 当仿真结果同样为 `W/(m²·sr·μm)` 时可选择“绝对值对比”；否则使用归一化模式比较谱形。
6. 为保证物理可比性，仿真应使用对应样本记录的经纬度、观测时间、卫星天顶角、
   卫星高度以及太阳几何条件。

原始 NetCDF 中的三个辐亮度变量是四维数组，当前验证界面不能直接将其作为一维
光谱选择，因此应优先导入上述 `.npz` 文件。需要换用其他视场时，可执行：

```powershell
python scripts\extract_cris_validation_spectrum.py <原始CrIS.nc> <输出.npz> --indices ATRACK XTRACK FOV
```

从 NOAA `SCRIF` 与配套 `GCRSO` 文件按目标位置自动选择最近的质量合格 FOV：

```powershell
python scripts\extract_noaa_cris_sdr_spectrum.py <SCRIF.h5> <GCRSO.h5> <输出.npz> --latitude <纬度> --longitude <经度>
```
